# API handler rules

Loads when editing any file under `src/api/`.

## Handler signature

- Every handler is `async function handle(req: ApiRequest<TBody>): Promise<ApiResponse<TOut>>`. The framework adapter does the actual response write â€” handlers never call `res.send`.
- The `TBody` and `TOut` type parameters come from the schemas in `src/api/_schemas/`. Inline anonymous types here are not allowed.

# React component & page rules

Loads when editing any file under `src/components/` or `src/pages/`.

## Imports

- Import React types as `import type { ... } from "react"` â€” never mixed with value imports. This keeps the dead-code-elimination boundary obvious.
- App-internal imports use the `@/` alias (resolved by Vite). Relative `../../../foo` paths are a code smell â€” promote the shared module instead.

# Test file rules

Loads when editing any co-located test file anywhere in the tree. Applies on top of the React or API rules when the file under test sits in those directories.

## Structure

- One top-level `describe` per file, named after the unit under test (`describe("Cart", () => { ... })`).
- Group related cases with nested `describe`. Avoid deeper than 2 nesting levels.
